## 4. Session SD directory (what `launch_playable.py` + `run_isolated.prepare` create)

`playable-r1/sessions/<name>/` contains `Azahar.app` (an independent copy), `plan.json`, `process.json`, `launcher.log`,
`screenshots/` and `user/`.

`user/config/qt-config.ini` is portable: is_new_3ds per `old|new`, virtual SD at `user/sdmc`, with `lle_applets=false` and a
screenshot path added. `run_isolated` writes `user/sdmc/sm64ds/env.txt`. The launcher copies it to `user/sdmc/3ds/sm64ds/env.txt`
and deletes `autoexit`. `env.txt` holds `SM64DS_FRESH_NATIVE=1`, `SM64DS_FRESH_NATIVE_ASSETS=sdmc:/3ds/sm64ds/native`,
`SM64DS_SAVE_PATH=sdmc:/3ds/sm64ds/playable.sav`, the extra `KEY=VALUE` args, and `SM64DS_REQUIRE_3DS_MODEL=<model>`.

`user/sdmc/3ds/sm64ds/` holds:
* `settings.ini`: `[debug] dumps=$PLAYABLE_DUMPS show_fps=1`, or a copy of `$PLAYABLE_SETTINGS_FROM`.
* `owner-rom.nds`: copy of `build/roms/europe.nds`.
* `native/`: the bank set above.
* `prepared.sm64ds`: only when `$PLAYABLE_PREPARED_FROM` is set. Otherwise the game prepares it from `owner-rom.nds` on first boot.

`user/sdmc/3ds/dspfirm.cdc` is copied from the personal Azahar profile (read-only use). When `PLAYABLE_CIA` is set, the CIA
is installed with `azahar -i` and the `.app` under `title/00040000/0f5365*/content/` is launched.

Further launcher env vars: `PLAYABLE_LAB_BANK`, `PLAYABLE_LAB_NATIVE_FROM` (labs only).

The launcher refuses to start if any `azahar` process is live, and it serialises preparations with `playable-r1/azahar-launch.lock`.

Recorded input recipes (from the campaigns):
* bob: `SM64DS_NATIVE_COURSE=bob SM64DS_PLAYABLE_SCRIPT=k:900:1:2,k:1000:1:2,k:1100:1:2,k:1200:1:2,k:1300:40:160,k:1480:10:160,k:1660:41:100,k:1780:80:50` (107 dropped `,k:1850:302:2`).
* intro: `SM64DS_PLAYABLE_SCRIPT=t:220:160:120:6,t:1100:160:210:6,t:1500:60:80:6`.
* Common to both: `SM64DS_GAME_FRAME_LIMIT=3000|6500`, `SM64DS_FRESH_NATIVE_PROFILE=0`, `SM64DS_NATIVE_LOAD_TRACE=0`, `SM64DS_PLAYABLE_SHOTS=`.

Format (SM64-3 #484): `t:FRAME:X:Y:LEN` (touch), `k:FRAME:HEXMASK:LEN` (keys).

## 5. Ordered rebuild recipe (from scratch; keep one emulator at a time)

Run everything from the project root (`P=build/native-renderer`, `R=$P/recovered`).

1. **ROM.** Unzip `Super Mario 64 DS EUR.zip`, rename the file to `build/roms/europe.nds`, and check SHA1 `1367529f…`.
2. **Python environments** as in section 2. Also run `python3 tools/setup_dependencies.py` for `build/dependencies/sm64-port-3ds`.
   Provide `SM64DS_MOTION_ANIMS` (209 private `anim_*.inc.c`, see `docs/BUILDING.md`). `build_integrated_native.py` needs both.
3. **Base tree.** Run `DEVKITPRO=… DEVKITARM=… .venv/integrated-native/bin/python tools/build_integrated_native.py --render60 --rom-only --jobs 8`.
   This produces `build/integrated-native/render60-source`. It also **reserves** a BUILD number: `build_version.hpp` goes 107→108,
   so step 9 must then use ≥109.
4. **Cook the six non-model catalogs** with the section 3 commands (same output paths). Model banks/header: `cp -R $R/romfs-from-cia107/native $P/playable-r1/catalog-approx-r8`.
   This is exact. Re-cooking with `author_catalog.py` is possible but may differ.
   Cross-check the cooked `.nim/.nmd` files against `$R/romfs-from-cia107/native/` by sha256:
   00000 `94e3a65b…`, 00001 `033a36fd…`, 04096 `cc99a3c6…`, 06000 `3886b6be…`, 05001 `a456703a…`.
5. **Headers:** `python3 $R/game-runtime-20261026-r1/compose_native_headers.py --out $P/headers-r1 --model $R/romfs-from-cia107/native/native_catalog.hpp`
6. **Recreate the checkout under the same name** (all scripts hard-code `game-runtime-20261026-r1`):
   1. Copy `render60-source` to `$P/game-runtime-20261026-r1/source` with the #3666 ignore list (the `shutil.copytree` call, without the old `prepare(...)` line).
   2. `(cd $P/game-runtime-20261026-r1/source && python3 ../../recovered/game-runtime-20261026-r1/patch_native_test_entry_sm64-3_979.py && sed -i '' '/setenv("SM64DS_PIPELINE","0",1);/d' port/platform/3ds/game_entry.cpp)`.
      Do this before `prepare`, as in the history, so the receipt hashes stay valid.
   3. `python3 tools/prepare_integrated_native_renderer.py --source $P/game-runtime-20261026-r1/source --runtime --catalog $P/headers-r1/native_model_catalog.hpp --image-catalog …image… --menu-catalog …menu_cell… --menu-obj-catalog …menu_obj… --menu-backdrop-catalog …menu_backdrop… --canvas-catalog …canvas… --background-catalog …background…`
   4. Copy `refresh_native_overlay.py` next to `source/`.
   5. Run the #3667 configure (`configure_and_build_smdev3667.sh`).
7. **Restore the playable-r1 scripts** from `$R/playable-r1/`, plus `$R/hardware-report91/settings.ini` → `$P/hardware-report91/`.
   Copy `~/Applications/azahar/azahar-macos-arm64-2126.2/Azahar.app` to `build/crash-fix-00000005/session-old-missing-1792948097097031000/Azahar.app`,
   or edit the `app =` line.
8. **Package art.**
   * `mkdir -p build/integrated-native/package-cc51967a3eb54678 && cp $R/package-art-from-cia107/banner.bnr` into it.
   * Make `icon.png` with `build/python/bin/python -c "from PIL import Image;Image.open('assets/icons/mario-yellow-approved.png').convert('RGB').resize((48,48),Image.Resampling.NEAREST).save('build/integrated-native/package-cc51967a3eb54678/icon.png')"`.
     This is the `tools/package_integrated_cia.py` `artwork()` recipe.
9. **Build:** `zsh $P/playable-r1/build_playable.sh 108 > $P/playable-r1/build108-driver.log 2>&1`. Expect `Verified overlay; refreshed [...]` and `built game-p108 (BUILD 108)`.
10. **Test session.**
    * `prepared.sm64ds`: first run one session without `PLAYABLE_PREPARED_FROM` and let the game create it. Then place it at
      `$P/playable-r1/sessions/bob-p41-old-c/user/sdmc/3ds/sm64ds/prepared.sm64ds`, the path the campaign hard-codes.
    * Derive `profile108-campaign.py` like #1790 (replace `runs=` with `('game-p108','bob108-old','old','bob',3000)`) and run it.
    * Check that frames advance and the screen is not black.
11. **Package:** `python3 tools/package_native_renderer_hardware.py 108 bob108-old` → `$P/playable-r1/hardware/build108/SM64DS-Native-BUILD108.cia`.
    Then do the installed-CIA check as in #1819, and the delivery as in #1840.
