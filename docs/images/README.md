# README imagery

`build-24-pause.png` is an unchanged 400×480 native display capture from the
local BUILD 24 Azahar New-model session. It shows Bob-omb Battlefield and
the actual pause interface, including the visible BUILD label. It is emulator
evidence, not a photograph of a physical console or a hardware FPS claim.
The pixels have not been repainted or upscaled. The original game artwork
belongs to Nintendo; interface adaptation is part of this project.

`badges/` contains project-authored SVGs for fixed facts: development state,
target platforms, the current local candidate and component-specific license
scope. These badges do not claim CI success or a public release. Update the
build badge when the README's current candidate changes.

The approved 3D logo used for local CIA packaging remains under
`assets/banners/approved-logo-v2/`; raw references and abandoned design
iterations remain local. No unrelated port's hero or branding is reused.
